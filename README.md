# Info

QField-putkiprojektin ohjesivusto. Korjattavaa:
- teema
- sisällöt
- ohjeiden syöttäminen Wordista tähän pohjaan

## Ohje:

> pip install mkdocs
> cd my-project
> python -m pip install -e ".[docs]"
> pip install mkdocs-material

> python -m mkdocs serve

Sivusto nähtävissä osoitteessa: 
localhost:8000
